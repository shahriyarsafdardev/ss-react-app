### Install ASDF

Add the asdf plugin to `~/.zshrc`, as described [here](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/asdf).

Install asdf through `brew install asdf`.

Add plugins:

1. asdf plugin add nodejs
2. asdf plugin add yarn
3. asdf plugin add ruby

More documentation is included [here](https://asdf-vm.com/guide/getting-started.html)

Install packages through `asdf install`.

### Install Yarn

`npm install --global yarn`
`yarn install`
